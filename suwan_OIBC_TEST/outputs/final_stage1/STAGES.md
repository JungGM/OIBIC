# 최종 실행 단계

1. **기준 모델 재현·비교 확정 — 비교 완료**: 고정 배치에서 JungGM 공개 조합과 로컬 선택 조합 비교, 독립 채점, 원본·코드·모델 해시 검증, 저장 강화 모델 개발 예측 재현 통과. 원저자 보고 수치와 강화 모델 수치 차이는 남아 있으며 RESULTS.md에 명시했다. 기존 공식 기간 생산 작업은 별도 진행 중이다.
2. 집합 오차 보정 — 완료. 복잡한 조건부 회귀보다 작은 배율 보정이 내부 검증에서 우수.
3. 예보 변동 특징 추가 — 완료.18특징,143특징 XGBoost를 동일1532570행에서 비교.
4. 직접 집합 예측 대안 — 조건부 생략. 앞 후보가3월 내부 검증에서 개선.
5. 발전소 배치 최적화 — 완료. 새 배치·특징·배율 후보의4월 패널티1.276% 감소, 부트스트랩 하한 음수로 원래 게이트는 실패. 이후 사용자가 점수 개선을 근거로 해당 후보 채택을 명시적으로 지시했다. ADOPTION.json에 기록.
6. 최종 검증·제출 산출물·GitHub 정리 — 완료. 사용자 채택 후보로 최종 학습·파일 교체, 저장 모델 예측차0·CSV 재생성 해시 일치·시간축·야간·용량 검증 통과. GitHub main에 최종 코드와 결과 게시. 기준 파일은 submission_reference에 보존.

이전부터 실행 중인 재현 파이프라인의 배치 검색과 공식 기간 파일 생성은 기준 시스템 재현에 포함된다. 이를 우리 신규 5·6단계 완료로 취급하지 않는다. 신규 보정 자동 실행은 run_all.ps1에서 해제했다.

이번 단계는 새 모델을 학습하거나 4·5월 결과로 앙상블 비율을 다시 선택하지 않는다. 4·5월 비교는 이미 지정된 두 비율의 진단이며, 이 자료가 이후 완전히 미사용한 검증이라고 주장하지 않는다.

감사 호환 수정: 재개 기능이 만든 *_checkpoint.json은 모델 메타데이터가 아니다. 복사본 audit_run.py에서 이 파일만 메타데이터 열거에서 제외한다. 원본 학습·예측 Python 파일은 변경하지 않는다. 체크포인트 해시는 compare.py에서 별도 검증한다.
