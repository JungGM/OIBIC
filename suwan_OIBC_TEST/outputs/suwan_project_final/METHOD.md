# 방법과 출처

JungGM은 같은 팀의 기준 모델이다. 기준 모델의125특징·용량 가중 학습·7모델 선택·정산식·기존 그룹 최적화를 독자 개발했다고 주장하지 않는다. 원본은 JungGM/OIBIC의73d269f69ce059cabbee1c4f68a2cb05ce4d1aac 커밋이다. 원본 코드는 이 폴더에 재게시하지 않고 bootstrap.py로 고정 커밋에서 받아 Git blob 해시를 검증한다.

이번 기여는 독립적인 기준 비교, 시간 외 집합 오차 보정, 예보 변동 특징18개, 제한된 추가 실험, 후보의 채택/탈락 기록과 최종 파일 검증이다. 새 기능을 구현했다는 사실과 채택됐다는 사실을 구별한다.

## 식

정산 패널티는 P=0.1 Σ_t SMP_t k_t Σ_g |B_gt−A_gt|다. 발전소별 절대오차 합이 아니라 그룹 합계에 절대값을 적용한다.

기본 예측 B는 기준 LightGBM20% + L1 LightGBM40% + XGBoost40%의 발전소 예측 합이다. 이 비율은 사전 선택 구간에서 정했다. 공개 비율20/30/50도 같은 환경에서 비교한다.

잔차 R=B−A를 용량으로 정규화하고, 표준화된 예보 특징 z에 대해 Σ w|R/c−θz|+α||θ||₁를 최소화한다. w는 과거 SMP×k다. 출력은 max(0,B−λ clip(cθz,−0.1B,0.1B))이며 야간은0이다. 미래 실제가격은 모델 입력에 들어가지 않는다. 정규화·결측 중앙값·회귀계수는 적합 구간에서만 학습한다.

배율 대조군은 과거 A/B의 가중중앙값을 쓴다. 가중치는SMP×k×B이며 B>1인 시각만 사용한다. 배율은0.9~1.1, 적용 강도는0.25/0.5/1로 제한한다. 직접 집합 예측 대안은 기본 예측 B를 특징에서 제외한다.

새 특징은 같은 발표분의 운량/UV 1·2시간 차분,3시간 표준편차·범위, 태양고도 가중 주간 평균·편차다. 목표일·발전소 경계를 넘지 않으며 결측 시간 간격을 압축하지 않는다. 미래 실측이 아닌 이미 주어진 예보의 일중 경로만 쓴다.

## 논문 활용의 범위

- 사용자 제공 Hybrid multi-scale feature extraction 논문: 여러 시간 규모의 변화·변동성 특징이라는 발상. 제공되지 않은 일사량과 시험 기간 발전량 lag를 쓰지 않는다.
- 사용자 제공 A sample robust optimal bidding model for a virtual power plant: 불확실성과 시간 순 검증에 대한 동기. ESS·입찰 최적화나 SRO 자체를 이번 코드에서 구현한 것은 아니다.
- 사용자 제공 Are better combinations of DERs more profitable: 정산 구조와 자원 조합을 함께 고려한다는 원리. 이번 배치는 실제 시간 외 예측 잔차를 사용한다.
- [지역 계층 태양광 예측 연구](https://arxiv.org/abs/2403.01653): 발전소와 집합 수준 정보의 결합이라는 가설. 원 논문의 신경망과 과거 발전량 입력을 그대로 구현하지 않았다.

## 검증 한계

2024~2025년 자료는 여러 번 검토했다. 이번에도3월 내부 선택,4월 채택 판단,5월 고정 후 보고의 순서는 지키지만 연구 전체의 미사용 시험이라고 부르지 않는다. 후보는4월에 하나만 평가하고 실패한 뒤 다른 후보를 계속 대입하지 않는다. 5월은 최종 계수 선택에 쓰지 않는다. 날짜 상관을 고려한3일 블록 부트스트랩은 안정성 진단이며 계절 일반화를 보증하지 않는다.

2024년은 전체253개가 동시에 관측된 시간이178시간으로 짧다. 그 구간과2025년 전체253 관측 구간을 합쳐 하나의 연간 개선율로 표시하지 않는다. 공식 평가기간의 실제 발전량이 없으므로 공식 점수·순위·우승 여부는 알 수 없다.

## 최종 채택에 대한 사용자 결정

추가 후보의3·4·5월 패널티가 모두 로컬 기준보다 감소했으나4월 안정성 게이트 하한은 음수였다. 이를 설명한 뒤 사용자가 확인된 개선을 근거로 해당 후보 채택을 지시했다. 원래 게이트와5월 전 고정 후보는 수정하지 않고 ADOPTION.json을 별도로 추가했다. 최종 채택은5월 결과를 본 뒤의 결정이며, 독립 시험에 근거한 선택이라고 표현하지 않는다. 후보의 특징·계수·배치는 새로 튜닝하지 않는다.
