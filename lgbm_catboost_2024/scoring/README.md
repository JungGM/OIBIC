# 세 사람 공통 test기준 v1

이 폴더는 제출 파일 자체가 아니라 동일 조건 비교 규약과 로컬 채점기다. 남이 만든 예측 CSV는 정답이 아니므로 공통 정답으로 사용하면 안 된다. 정답은 각 팀원이 가진 배포 generation.parquet다. 원본·정답·모델·예측 CSV는 공개 GitHub에 업로드하지 않는다.

## 고정 조건

- 학습 정보: 2022-01-01 01:00~2023-12-31 17:00 KST의 제공 자료. 외부 데이터/모델 금지. 2024년 실적·실측 기상은 입력 및 설정 선택 금지.
- 예측 입력: 대상일 전날 17시까지 발행된 10시/17시 예보, 제공 메타, 결정적인 시간/태양 기하 특징. 실측 기상으로 예보를 바꿔 넣지 않는다.
- 모든 선택 단계는 다음 검증 첫날 전날 17시 이전 자료로 끝낸다.
- 예측 범위: 2024-01-01 01:00~2025-01-01 00:00, 8,784시간. 윤년이다.
- composition.csv: site_id,group, 253행. 전체 발전소 각각 한 번, G1/G2 각각 최소 20,000 kW.
- forecast.csv: group,ts,forecast_kwh, 17,568행. +09:00, 음수/결측/무한대/중복 금지. 실제가 없는 시간도 예측한다.
- 비교 단위: 각자의 예측 모델+그룹 전체 시스템. 예측 모델만 비교하려면 모두 참조 A→G1/B→G2를 별도로 출력한다.
- 2024년은 이미 결과를 확인한 공개 비교 기간이다. 이를 보고 수정하면 개발 평가이며 미사용 최종 평가가 아니다. 수정 횟수와 사유를 기록한다.

## 채점과 한계

253개 발전소 실적이 동시에 존재하는 공통 시각만 대회식으로 채점한다. 결측 정답을 0으로 만들지 않는다. 현 배포 자료에서는 178시간으로 겨울에 편중되어 있다. 이 순위만으로 연중/대회 우승 모델을 고르면 안 된다. 발전소별 예측을 로컬 공유할 수 있으면 별도로 월별 관측 MAE/RMSE, 주간 오차, 신규 발전소를 비교한다. 서로 다른 그룹의 시계열을 그대로 MAE 비교하는 것은 부적절하다.

각자 모델 설정·그룹·코드 해시를 확정하고 예측 파일을 봉인한 후 같은 채점기를 한 번 실행한다. 결과와 해시를 팀 내 비교한다. 공식 서버에는 이 파일을 제출하지 않는다.

```powershell
py "test기준/score_2024.py" --data "배포폴더" --composition "본인폴더/composition.csv" --forecast "본인폴더/forecast.csv" --out "본인폴더/score.json"
```

점수: 매전수익 - 0.10 × Σ SMP × k × |그룹 예측-그룹 실적|. 절대값은 그룹 합산 이후에 계산한다. k는 종료시각 11~15시이면 3, 나머지 1. 수익은 모든 그룹 배정에서 동일하므로 벌금이 낮을수록 좋다. 이 검사는 파일 구조와 로컬 계산이며 공식 규정 전체나 서버 승인을 보증하지 않는다.

실제 모델 v2의 파일은 로컬 결과 폴더에 생성된다. 이 저장소에서 내려받아야 할 비교 기준은 README와 score_2024.py이며 다른 사람의 예측값을 답으로 쓰지 않는다.
