# 6단계 전체 재학습·2024 예측 완료

2022-01-01 01:00~2023-12-31 17:00 KST, 유효 정답 1,444,607행·148개 발전소로 두 모델을 재학습했다. LightGBM 160개 특징·484회, CatBoost 160개 특징·600회를 고정 설정으로 학습했다. 조기 종료나 설정 재선택을 하지 않았다.

2024-01-01 01:00~2025-01-01 00:00 KST의 8,784시간을 253개소 전부 예측했다. 학습 이력이 없는 105개소도 포함했다. 각 모델의 발전소 예측을 0 이상으로 제한하고 50:50 혼합을 참조 A→G1/B→G2로 합산했다. 추론에는 실제 발전량·실측 기상·실제 SMP를 사용하지 않았다.

CatBoost 양자화 API가 지원하지 않는 thread_count 인자를 수정했다. 메모리 사용을 줄이기 위해 254개 border로 양자화한 약 243MB 자료를 별도 프로세스에서 저장하고, 새 프로세스에서 불러 전체 학습했다. 학습 행이나 모델 설정을 줄이지 않았다. 재현 명령은 README에 반영했다.
