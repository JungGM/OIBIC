# 특징 확장: 기존 104개 + 신규 56개 = 160개

2026-11-01. 최신 특징 목록은 OIBC_feature_manifest_160.json이다. 모델은 공유 LightGBM + CatBoost 구조를 유지한다. 두 모델 모두 같은 160개 입력 열을 받으며 관측소 ID는 범주형으로 처리한다. 아래는 설계 추가이며 실제 특징 행렬 생성·학습·성능 검증은 아직 수행하지 않았다. 특징 수는 후보 수이고 최종 채택 수가 아니다.

## 추가 판단

원본 시간별 예보는 구름과 날씨의 연속성, 예보 출처 사이의 분산, 일출·일몰 경계에서 대기를 통과하는 경로의 차이, 눈·결빙 조건의 누적을 명시적으로 표현하지 못한다. 이 정보는 제공된 예보와 천문 계산만으로 만들 수 있어 신규 발전소에도 적용 가능하다. 반면 과거 발전량 기반 특징은 미관측 발전소에서 사용할 수 없으므로 이번 추가에서 제외한다.

## 수식과 해석

### 시간 변화·일일 맥락

v는 같은 발행 묶음의 예보다. Δ^-v_t=v_t−v_(t−1), Δ^+v_t=v_(t+1)−v_t. 3시간 평균·표준편차·범위는 t−1,t,t+1을 사용한다. 세 시각이 모두 같은 대상일 발행 묶음 안에 있고 정시·유효한 경우에만 계산한다. 인접 미래 시각의 예보는 이미 전날 발표된 정보이므로 사용할 수 있지만, 다음 날 더 늦게 발행된 예보를 이어 붙이면 안 된다.

운량의 태양가중 평균은 μ_c=Σ_t q_t c_t/Σ_t q_t, 표준편차는 sqrt(Σ_t q_t(c_t−μ_c)²/Σ_t q_t). 하루 강우량은 시간 강우량의 합이다. 전체 날짜 예보를 한 번에 보는 것은 가능하지만 평가 연도 전체의 통계를 계산하는 것은 금지한다. 하루를 구성하는 데 필요한 필드가 누락되면 해당 집계는 NaN으로 둔다.

### 불일치

각 v에 대해 d_v=|v_A17−v_B17|, s_v=std(v_A10,v_A17,v_B10,v_B17). s_v는 유효한 값이 두 개 이상일 때만 계산한다. 네 예보는 독립적인 확률 앙상블이 아니므로 s_v를 예측 표준오차나 신뢰구간으로 해석하지 않는다. 기존의 부호 있는 차이는 방향을, 새 절대차는 불일치 크기를 표현한다. 트리에서도 절댓값 표현은 대칭적인 분기를 단순화할 수 있으나 개선은 보장되지 않는다.

### 태양·열 관련

I0는 날짜별 대기권 밖 법선 복사량. 새 특징은 H0=mean(I0 max(sin α,0))이며 표면 GHI·맑은 날 발전량이 아니다. q²와 q³는 초기 트리의 깊이를 줄이는 데 도움이 될 수 있는 변환이며 새로운 독립 정보는 아니다. Kasten–Young 상대 공기질량은 태양 천정각으로 계산하고 태양이 지평선 아래면 NaN으로 둔다.

제공사별 냉각 상호작용은 q×w, 고온 상호작용은 q×max(T−25,0)/(1+w)로 정의한다. w는 m/s 수치이며 분모의 1은 1m/s 기준을 의미하는 경험적 정규화다. 25도는 기준값일 뿐 실제 패널 온도 임계값이 아니다. 실제 모듈 온도나 효율 감소량을 계산했다고 주장하지 않는다. 기온·풍속이 모듈 열 거동에 관계한다는 물리적 지식에서 출발한 모델 입력이다.

### 적설·결빙 위험

각 제공사의 같은 대상일 17시 예보에서 t−5~t를 사용한다.

- S6=Σ snow_h (mm 강설깊이; 물환산 적설량 아님).
- CS6=Σ snow_h 1(T_h≤0).
- PDD6=Σ max(T_h,0)×1h.
- WF6=Σ 1(T_h≤0 and (rain_h>0 or snow_h>0)).

필요한 6시간 필드가 모두 있을 때만 계산한다. 대상일 초기에는 이 값이 결측일 수 있다. 과거 관측이나 나중 발행 예보를 임의로 채우지 않는다. 패널에 남아 있는 실제 눈, 전날부터 지속된 적설, 패널 경사·미끄러짐을 알 수 없으므로 이는 제한적인 같은 날 위험 신호다. 실제 snow coverage 모델을 대체하지 않는다.

## 정보 경계·결측

- 물리적 대상일은 종료시각 D 01:00~D+1 00:00의 24시간이다. 자정 종료시각을 다음 대상일로 잘못 넘기지 않는다.
- 해당 대상일의 전날 17시까지 발행된 예보 묶음을 고정한다. 날짜를 넘어갈 때 round=17이라는 숫자만 보고 이어 붙이지 않는다.
- 날씨 NaN은 유지한다. 가용성 4개는 키 존재, 추가 신뢰도 4개는 변수별 유효 셀 비율이다. 이 둘은 다르다.
- canonical field는 기본 A 8개·B 20개 원본 변수로 정의한다. A의 거의 중복 기온 max/min은 제외하고 풍향은 인코딩 전 한 셀로 계산한다. 제공사별 일일 커버리지는 유효 셀 수/(24×canonical 변수 수), 주변 커버리지는 유효 셀 수/(3×canonical 변수 수)다. 날짜 밖 슬롯은 미가용으로 센다.
- 음수 강수·강설·풍속 등 무효 입력은 파생식 적용 전에 NaN으로 처리한다. 운량·습도 등의 범위 이탈 처리 정책은 학습 구간에서 고정하고 평가에도 동일 적용한다.
- 좌표는 천문 계산에만 사용한다. 외부 실측 일사량·위성·전체 평가년도 통계는 추가하지 않는다.

## 검증 순서

초기 104개를 기준으로 2023년 순방향 검증 예측을 만들고, 추가 묶음의 효과를 확인한다. 우선순위는 시간 변화·일일 맥락 → 예보 불일치·품질 → 물리 상호작용 → 눈·결빙 위험이다. 모델 계열을 추가 탐색하지 않고 특징 묶음의 유효성을 확인한다.

전체 성능 외에 미관측 발전소 가정 holdout, 월별 오차, 11~15시 오차, 편향을 확인한다. 그룹 실적이 없는 시간을 채워 점수를 만들지 않는다. 최종 미사용 검증 구간은 특징 선택에 반복 사용하지 않는다. 2024년 실적·점수로 후보를 선택하지 않는다. 중요도가 높다는 이유만으로 채택하지 않고 추가 묶음을 뺐을 때의 검증 손실과 안정성으로 판단한다.

## 보류한 후보

- 발전량 lag·이동평균·발전소별 과거 성능: 신규 발전소에 부재하고 실적 수신시각도 불명확하다.
- 실측 기상 lag 기반 적설 상태: 관측시각과 실제 수신 가능시각 확인 전 보류한다.
- 장기간 잔존 적설 시뮬레이션·실제 패널 온도: 필요한 패널 경사·일사·적설 상태 자료가 없다.
- 정교한 clear-sky/POA 모델: 경사·방위·대기 탁도 등에 가정이 필요해 초기 특징에 넣지 않는다.
- 요일·공휴일: 태양광 자체에 직접적인 물리 효과가 약하고 출력제어의 간접 신호일 가능성이 있어 후순위다.
- 관측소 target encoding: 시간 분할별로만 생성해야 하고 신규 범주 추정의 불확실성이 있어 초기 추가에서 제외한다.
