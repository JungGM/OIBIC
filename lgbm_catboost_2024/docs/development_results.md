# 4단계 첫 학습·개발 검증 완료

2026-11-01. 실제 데이터로 모델 4개(기본 2개, 발전소 제외 2개)를 학습했다.

## 실행 범위

- 학습: 2022-01-01 01시~2022-12-31 17시 KST, 470,925행·80개소.
- 개발 검증: 2023-01-01 01시~2023-09-30 17시 KST, 679,143행·119개소.
- 특징: 160개. 용량·과거 SMP·피크 가중 L1. 두 모델 혼합은 사전 고정 50:50.
- 전체 학습 캐시: 2022년 471,485행, 2023년 973,122행. 공통 최종 학습 마감 2023-12-31 17시. 음수 정답 20행 제외, 0 발전량 유지.
- 정답 결측을 채우지 않았다. 2023년 10~12월 최종 확인은 미평가. 2024 실적은 모델 선택·학습에 사용하지 않았다.

## 기본 모델 결과

| 모델 | 시간당 발전소 MAE(kWh) | 용량 대비 MAE(%p) | 가중 MAE(%p) |
|---|---:|---:|---:|
| lightgbm | 3.6138 | 4.0869 | 6.2035 |
| catboost | 3.6246 | 4.1186 | 6.2186 |
| blend_50_50 | 3.5763 | 4.0553 | 6.1480 |

50:50 혼합의 가중 오차는 LightGBM 단독보다 0.894% 낮았다. 개발 검증 결과이며 최종 미사용 평가나 공통 2024 그룹 점수가 아니다. 개별 오차 합 대리 손실로 그룹 오차 상쇄의 이득을 측정할 수 없다.

## 재현과 보관

저장 모델 재로딩 후 128개 행의 두 모델 예측이 원래 저장된 예측과 일치했다. 캐시 목표값·가중치·키 검사, 이전 특징 엔진과 벡터화 엔진의 160개 특징 일치 검사도 통과했다. 모델·발전소별 예측은 work/development-v1에 로컬 보관했다. 코드는 work/OIBIC/lgbm_catboost_2024/scripts/prepare_training.py와 train_validate.py에 있다.

8GB 메모리 환경에서 실행되어 CatBoost 학습이 느렸다. LightGBM 기본 484 trees, CatBoost 기본 600 trees. CatBoost는 상한에 도달했으므로 충분히 수렴한 최적 설정이라고 단정하지 않는다. 작은 개선폭의 통계적 유의성은 평가하지 않았다.

다음 5단계: 개발 구간에서 특징 묶음과 혼합 비중을 정하고 설정을 고정한 다음, 미사용 10~12월 구간을 한 번 평가한다. 아직 2024 예측·공통 채점·GitHub 업로드는 수행하지 않았다.
