# 177-feature XGBoost submission

2026-11-03 기준 제출 후보: 177개 특징 XGBoost 단독, 기존 G1/G2 배정, 보정 및 앙상블 없음. 이 폴더는 실행 코드와 집계 결과를 기록한다.

- 최종 학습: 2021년~2025-05-31 17:00 KST, 유효 주간 표본 2,189,472행.
- 300 trees, max_depth=8, learning_rate=0.03. 타깃은 설비용량 정규화 발전량; 가중치는 과거 SMP × 시간 가중치 × 설비용량.
- 과거 검증(2024-12-31 학습 마감, 2025년 1~5월, 253개소): 52개 특징 벌금 76,648,860원, 177개 특징 73,554,800원 (4.04% 감소). 3~5월은 각각 50,464,895원과 47,898,578원 (5.09% 감소). 과거 개발자료이며 공식 평가 점수가 아니다.
- 제출 파일 검증: 발전소 253개, 그룹당 20,000kW 이상, 각 그룹 8,760시간, 총 17,520행. 서버 제출 여부는 이 저장소로 확인할 수 없다.

## 재현 자료와 경로

이 코드는 작업 당시 소스 사본이다. 원본 대회 데이터, 특징 캐시, 학습된 모델, 발전소별 예측 및 제출 CSV는 포함하지 않는다. 코드는 기본적으로 작업 디렉터리 아래 `work/data`, `work/OIBIC/lgbm_catboost_2024`와 이 폴더에 해당하는 `work/xgb1103-improve` 경로를 참조한다. 실행 전 로컬 환경에 원본 제공 데이터와 해당 경로를 배치해야 하며, 경로와 캐시 준비에 맞춘 수정이 필요할 수 있다. 기존 모델·캐시를 덮어쓰지 않도록 새 경로를 사용한다.

`experiment.py prepare`와 `expand_features.py`는 학습 특징 캐시를 만들고, `build_submission.py train`은 최종 모델을 학습한다. `export_submission_float64.py predict`와 `validate`는 float64 용량 곱 및 합계 검증을 수행한다. 배포 환경 및 데이터 경로에 따라 명령은 조정해야 한다. 예보는 전날 17시 이전 발행분만 사용하며, 공식 평가연도 실제 SMP는 예측 입력에 넣지 않는다.

기상 특징 엔진은 저장소의 `lgbm_catboost_2024/src/features.py`와 `configs/features_160.json`에 의존한다. 필수 패키지: Python 3.12, numpy 2.3.5, pandas 3.0.1, xgboost 3.4.1, lightgbm 4.7.0, pyarrow 26.0.0, pvlib 0.16.1, scikit-learn.
